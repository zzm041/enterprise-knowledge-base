# Security scope and evidence
Verified in synthetic local tests: tenant/workspace/audience isolation; reader cannot write; hidden document ID gives 404; source eligibility before scoring; archive/version recheck around generation; invalid citation IDs fail closed; malformed provider vectors/scores are rejected; request/text/query sizes bounded; invalid API inputs omit submitted values; SQL values parameterized; HTTP endpoints loopback-only; no automatic source URL/file-path fetch; no provider body or credential logging.
Authentication uses server-side SHA-256 lookup of cryptographically random high-entropy tokens (not password hashing). Bootstrap stores generated tokens only under Git-ignored runtime, server config stores hashes. No hardcoded production token, anonymous bypass, .env import or upstream dependency.
Production gaps: static config credential revocation requires restart; no per-user throttle, SSO, TLS termination, malware scanning, tenant storage encryption or distributed revocation. Prompt constraints/citation IDs alone do not prevent all semantic prompt injection or prove truthfulness. No public deployment authorized.
All evidence is local synthetic engineering validation, not a security certification.
