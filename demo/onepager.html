端到端能力（不是功能列表，是能演示的路径）

四种角色：管理员 / 员工 / 主管 / 外部租户，越库 403
资料运营：新建 · 改版 · 下线 · 恢复 · 删除（手打标题确认）
批量：zip 整包、整目录导入、批量下线与导出
分类与检索：14 组标签树、搜索标题或 ID、版本 diff
多模态：扫描件 OCR、图片直接入库、读图用完即卸
助手层：意图分流、多轮改写、拒答兜底、未解决台账
可配置：兜底话术三入口（启动参数 / 面板 / 接口）
公开演示：只读 + 口令 + 限流 + 伪造身份无效
运维：质量看板、变更审计、VACUUM 备份、故障 fail-closed

边界：写清做了什么，也写清没做什么

  • 单机单进程：完整链路饱和 4 并发 / 0.98 rps，瓶颈是单卡生成
  • 语料 = 合成制度 90 篇 + 公开法规 7 篇，不是真实企业数据
  • 评测 = 自编 28 题 + 23 条助手用例，非盲测、非公开榜单
  • 鉴权 = 本地 Cookie 会话（PBKDF2 / 8h / 失败锁定）；无 SSO / OIDC
  • 无 CI/CD、无监控告警、无分布式副本

可验证性：这些数字凭什么可信

  • 54 项接口契约自检，脚本与页面同源，两端必须同时绿
  • 评测报告锁 corpus / cases 的 sha256，语料一改即报错
  • 改断言必须写明“旧断言为什么错”并进缺陷台账（PA-221…231）
  • 故障注入：杀网关后 /query 返回 fail-closed，页面与助手分别给专门文案
  • 备份：VACUUM INTO 0.02 s / 7.16 MB，integrity_check 双 ok
